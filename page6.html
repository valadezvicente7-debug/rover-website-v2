(Arduino rover module assignment 1 Arduino GPS)

Tutorial Introduction

This tutorial is how to link up an Adafruit Ultimate GPS Breakout - 66 channel w/10 Hz updates module to an Arduino and have it display your current GPS coordinates on request, and to make a program where it guides you to specified GPS coordinates. Both user interfaces will be used with the Arduino IDE Serial Monitor

Use in an Autonomous Rover Mission

This GPS module can be used to have our rover achieve GPS coordinates, and program movement and maneuver commands to reach them successfully. This can also be used to functionality point to the rover at true north

Required Electronics / Hardware

  • Adafruit Ultimate GPS Breakout - 66 channel w/10 Hz updates
  • Arduino Uno Rev3 (R3) or similar microcontroller
  • Arduino USB Cable
  • 4 jumper wires
  • External Antenna

Required Libraries

    • Github Library: https://github.com/mikalhart/TinyGPSPlus

    • SoftwareSerial.h (Included with Arduino IDE)

    • Arduino IDE

Instructions:

1. Connect 5V on Arduino to VIN on module.

2. Connect GND on Arduino to GND on module.

3. Connect Pin 2 on Arduino to RX on module.

4. Connect Pin 3 on Arduino to TX on module.

5. Insert sketches from figures 2-4 for different GPS module functionalities

(all Arduino Sketches written by Mikal Hart).

(Arduino rover module assignment 2 ultrasonic)

Tutorial Introduction

This tutorial explains how to connect and use an ultrasonic distance sensor (such as the HC-SR04) with an Arduino. By following and completing this tutorial, you will learn how the ultrasonic sensor works, how to wire it correctly, and how to write an Arduino sketch to measure distance. The final result allows distance measurements to be displayed in the Arduino Serial Monitor.

Use in an Autonomous Rover Mission

An ultrasonic sensor is commonly used on autonomous rovers for obstacle detection and avoidance. By continuously measuring the distance to objects in front of the rover, the Arduino can determine when the rover should stop, turn, or change direction. This helps the rover navigate its environment safely and autonomously.

Required Electronics / Hardware

  • Arduino Uno (or compatible Arduino board)
  • Ultrasonic sensor (HC-SR04 or similar)
  • Breadboard
  • Jumper wires
  • USB cable for programming and power

Required Libraries/References

No external libraries are required for this project. The sketch uses built-in Arduino functions such as pulseIn(), digitalWrite(), and Serial.

Wiring Diagram Description

The ultrasonic sensor is connected to the Arduino as follows:

  • VCC pin connected to Arduino 5V
  • GND pin connected to Arduino GND
  • Trig pin connected to Arduino digital pin 9
  • Echo pin connected to Arduino digital pin 8

(Arduino rover module assignment 3 - RF)

Tutorial Introduction

This tutorial focused on basic RF communication using an Arduino transmitter and receiver. The goal was to send a short message wirelessly (formatted like rover “coordinates”) and confirm that the receiver can read and display the incoming data reliably.

Use in an Autonomous Rover Mission

RF communication can be used for waypoint / beacon-style navigation where a remote transmitter repeatedly broadcasts a short coordinate message. A rover can listen for that message, parse the data, and use it as an input for navigation decisions.

Required Electronics / Hardware

  • Arduino board (Uno / Mega / compatible)
  • 433 MHz RF Transmitter module
  • 433 MHz RF Receiver module
  • Breadboard + jumper wires
  • USB cable for programming and power

Required Libraries/References

The RF transmitter and receiver sketches use the RadioHead (RH) library to handle RF communication. The library helps convert Arduino data into a radio signal for transmission and decode it on the receiving side.

  • RadioHead Library: https://www.airspayce.com/mikem/arduino/RadioHead/

Transmitter

The RF transmitter code for the Arduino tutorials was simple. The code uses the RadioHead library to enable the Arduino board to communicate with the RF devices. The library allows for the conversion of Arduino to radio frequency, which then could be transmitted on the 433hz transmitter. The transmitter was set up to repeatedly send a string of 12 characters (“coords”). The characters it would send are hard coded and for this tutorial were: X69ZZZZZZZZZ.

Receiver

The receiver code is similar to the transmitter code in that it uses the RadioHead library. With the library, radio frequency from the transmitter could be converted to something the Arduino could understand. The receiver is set up to be constantly searching for a radio frequency from a transmitter. Once the receiver grabs the info from the transmitter, it places it into a 12 character matrix via means of a for loop.
